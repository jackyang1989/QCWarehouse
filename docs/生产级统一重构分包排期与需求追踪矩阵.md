## 一、执行总则、经营合理性修订与硬性边界（§§00–02, §56, §§84–85, §95, §§105–112）

1. **核心经营范围与严禁膨胀边界（§§00, 56, 112.1）**
   - **自营三大核心服务**：`Product Inspection`（按委托件数/组逐件质检）、`Sample Comparison`（2–3 及以上批准组同屏横向对比）、`Golden Sample Matching`（确认样封存基准与比对）。
   - **明确排除范围**：不做多检查员/第三方服务商入驻与分账；不做代采购/代议价/代付货款/卖家退款仲裁；不出具认证实验室/CPSC/CE/AQL 抽检认证结论；不做电商商品链接 API/淘客抓取/ERP 商品主数据；不新增客户商品 Excel/CSV/粘贴批量建档为必填门槛；不接国内电子面单自动开单或承运商上门预约 API；不在 R2 引入客户离席自动扣款；不搞无限永久免费保管未检货物。
   - **轻量化下单与数据权威四分离（`R01–R05`, §§04.1, 57, 97, 112.1）**：
     - 购物车统一三步：**`Select Products`（从平台维护的标准商品目录 `Product Catalog` 选择类型、件数与影响报价的必要结构，无需录入商品名/SKU/供应商/采购单/图片/颜色尺码矩阵）→ `Configure Inspection`（结果导向易懂模块与覆盖数量，基础检查必要的身份核对/外观/标签/缺陷证据绝不二次收费）→ `Review & Pay`**；付款后在 **`Send Your Items`** 补充寄样运单与分组短码。
     - **四类数据权威严格分离**：① `Product Catalog`（标准商品目录 §04.1） ② `Product History`（已核身委托/报告自动沉淀的历史商品视图，禁止未确认自动合并，复用必重算现价） ③ `Physical Items`（仓库核身唯一实体与标签） ④ `Inspection Knowledge Base`（检测模板/SVG/双语词库）。
   - **现有生产认证能力保护（§00, FINAL-04, §108.4）**：业务方已确认 **Google 与 Microsoft 授权登录**均已在正式线上网站配置完成且香港 Stripe 通道已开通，严禁移除、降级或推倒重建；保留现行双 OIDC 登录与既有可靠能力并执行四端全链路回归验证。个人经营主体合法配置严禁要求虚假 `br_number`。
2. **强制技术与运营闭环不变量（§§34–40, 43–50, 59–70, 85–94, 106–112）**
   - **基础运营与备份先行（§74.1, §§85–89）**：高风险迁移前先做真实 `pg_dump` + 存量盘点核验（彻底移除 `triggers.length >= 5` 假健康 `LIF-012`）；首次安全 Owner 引导完成后，员工新增/72h 一次性邀请/自设 MFA/受控恢复/离职交接/最后有效 Owner 并发保护、动态 RBAC 与仓库/十类库区/耗材/工位设备校准/技能及调度接力全经正式后台完成，严禁以 SQL/fixture/`demo switch` 代替真实入口。
   - **强制私有对象存储（§§34–40）**：生产启用 Cloudflare R2 / AWS S3 / Backblaze B2 / 通用 S3；禁止本地盘或 `private_files` BYTEA 作长期主存；`original` 原图哈希永不覆盖；视频支持 `206 Range` 流；迁移工具按 `expand→migrate→verify→switch` 逐对象核验保持已发布 PDF 原字节哈希。
   - **唯一服务端定价内核与四端投影（§§06–10, 43, 90.2, 97）**：官网估价、客户购物车、后台模拟与正式报价同源计算；隐藏内部 `L1–L5`；`0` 默认折扣并精确命中草案算例 `\$17 / \$405 / \$122 / \$135`；商业价格/模板/运费/仓储发布走 **草稿→校验→非作者独立审批→发布/定时生效→回滚** 状态机；已确认交易写入不可变快照（含成交经营主体与商户账户实例 `FINAL-05`）。
   - **报告前独立 QA PDF 与合法退出闭环（§§44–50, 91.4–91.6, 106–109, 112.2）**：Inspection 后复核前生成候选 A4 PDF（3 商业 + 2 辅助，防存储膨胀 `R10`），QA 精准退回单点并原子发布同一冻结 PDF；区分已审批与已应用至任务的 `applied` 客户指令（§106）；区分整批送仓与部分抽检选样（§109）；支持报告前合法退回（`R07`）、发布后纠错撤销与零费重修（§91.6）、六维订单结案与退件重入库/售后重开（§91.4）、检后 15 自然日免费保管与独立付费 Golden Sample（30/90/180/365 天）、免密防扫描器 `GET` 预取 `/pay/[token]`、隐私与统一关户义务计算（§107）及五维事实一致性对账中心（§111）。
   - **一功能一提交 Git 规范**：每完成一个 `TASK-*` 即校验、测试、记台账并独立提交 Git，严禁破坏并行未提交草稿。
